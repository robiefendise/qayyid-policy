# Kebijakan Privasi (Privacy Policy) — QAYYID: Quran Typing App

**Terakhir Diperbarui:** 12 September 2026

Selamat datang di **QAYYID: Quran Typing App** ("Aplikasi"). Kami sangat menghargai privasi Anda dan berkomitmen penuh untuk melindungi data serta informasi pengguna kami. Kebijakan Privasi ini menjelaskan bagaimana Aplikasi kami mengelola data Anda.

---

## 1. Prinsip Utama: 100% Offline-First & Bebas Pelacakan

Aplikasi **QAYYID: Quran Typing App** dirancang dengan prinsip utama **Offline-First (Bekerja Penuh Tanpa Internet)**:
- Aplikasi ini **TIDAK mengumpulkan, TIDAK menyimpan di server eksternal, dan TIDAK membagikan data pribadi Anda ke pihak ketiga mana pun**.
- Aplikasi ini **TIDAK menggunakan cookie, pelacak analitik pihak ketiga, atau alat periklanan (bebas iklan / ad-free)**.
- Aplikasi ini **TIDAK memerlukan pendaftaran akun atau proses login** untuk menggunakan seluruh fiturnya.

---

## 2. Data yang Disimpan Secara Lokal di Perangkat Anda

Semua data progres pengetikan dan latihan Anda hanya disimpan secara lokal di memori internal perangkat Anda sendiri (*Local Room Database*), meliputi:
- **Histori Sesi Mengetik**: Skor akurasi, jumlah ketikan, waktu pengerjaan, dan jumlah kesalahan karakter.
- **Status Kekuatan Hafalan (SRS)**: Tingkat kemutqinan ayat (Mutqin, Lancar, Perlu Muraja'ah) untuk algoritma pengulangan hafalan harian Anda.
- **Pengaturan Aplikasi**: Pilihan tema tampilan mushaf, target sesi, dan jadwal pengingat muraja'ah lokal.

Data di atas sepenuhnya berada di bawah kendali Anda. Jika Anda menghapus data aplikasi atau meng-uninstall Aplikasi dari perangkat Anda, seluruh data lokal tersebut akan terhapus secara permanen.

---

## 3. Izin Perangkat (Device Permissions)

Aplikasi QAYYID hanya meminta izin perangkat seminimal mungkin yang diperlukan untuk menjalankan fitur esensial:
- **Penyimpanan / Media (Scoped Storage)**: Hanya digunakan saat Anda secara sukarela memilih fitur *"Bagikan Kartu Muraja'ah"* untuk mengekspor gambar kartu hasil latihan hafalan Anda ke galeri atau aplikasi perpesanan lain.
- **Notifikasi Lokal**: Digunakan semata-mata untuk memicu pengingat waktu muraja'ah terjadwal yang Anda atur sendiri di menu Pengaturan.

---

## 4. Perlindungan Data Anak

Aplikasi ini aman digunakan oleh semua kelompok usia, termasuk anak-anak yang sedang belajar atau menghafal Al-Qur'an. Kami tidak mengumpulkan informasi identitas pribadi apa pun dari anak-anak maupun orang dewasa.
